# Welcome to My Moving Box Realtime
Hi. Welcome to my repo. 

## Task
What is the problem? And where is the challenge?
We have the box and this box is located 70px from right and bottom. We have to move smoothly this box to the coordinates of bottom.
And this project happen during 35 second.

## Description
How have you solved the problem?
I have solved the problem using javascript methods. With helping getElementById i get div box. And with setInterval i move box every 0.5 second.
